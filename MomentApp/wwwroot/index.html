Features

Built for the conversation. Not the archive.

Nothing Retained

Messages live in memory for the life of the room and are never written to a database or a log. Calls are peer-to-peer, so audio and video never touch the server at all. When the room ends, there is nothing left to hand over.

Unanimous Save

100% yes vote exports a local file only. No vote — no record. The default is always disappearance, never storage.

Instant Room

Private room in under 15 seconds. No email, no phone, no identity. Name it, time it, share the link. Nothing more is needed.

Live Countdown

30 minutes to 3 days. The visible timer creates real urgency — a constant reminder that this moment will end.

Democratic Ending

Anyone can call a vote to close or extend. Majority rules. No single owner. Every voice — on ending, on saving — is equal. The room breathes as one.

Voice & Video

Peer-to-peer calls with no server recording. When the room ends, there is no footage — only memory.
